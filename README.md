# PeakPicker - TOF-SIMS スペクトル解析ツール

Version 2.0

TOF-SIMS（Time-of-Flight Secondary Ion Mass Spectrometry）スペクトルの解析用Pythonツールです。
MPAファイルの読み込み、ピーク同定、m/zキャリブレーション、自動ピークフィットなどの機能を提供します。

## 主な機能

### 基本機能
- MPAファイル（MPA4 ASCII形式）およびCSV/TSVファイルの読み込み
- 堅牢なファイル読み込み（複数エンコーディング対応、自動ヘッダ検出）
- スペクトルの可視化（TOF軸/m/z軸の切り替え表示）
- ズームイン/アウト、範囲選択
- ベースライン（BG）減算

### ピーク解析機能
1. **手動ピーク同定** - プロット上で範囲を選択してピークを同定
2. **m/z キャリブレーション** - 既知のピークからTOF-m/z変換式を計算
3. **自動ピークフィット** - 3つのレベルで自動フィット機能を提供

#### 自動フィットレベル
- **レベル1：単一ピーク自動フィット**
  - ユーザーが選択した範囲の単一ピークをGaussianフィット
  - 中心位置（TOF, m/z）、高さ、幅（σ, FWHM）、面積を自動取得

- **レベル2：範囲内ピーク自動検出＋一括フィット**
  - 指定範囲内で自動的に複数のピークを検出
  - 検出した各ピークを個別にフィット

- **レベル3：重なりピークの多峰フィット**（将来実装予定）
  - 複数のGaussianの和でオーバーラップしたピークをフィット
  - 2-3峰の分離が可能

### データ管理機能
- ピーク情報のテーブル表示（TOF, m/z, 高さ, FWHM, 面積など）
- ピークの選択・削除機能
- ピークリストのCSVエクスポート
- 積算結果のCSVエクスポート
- 設定の自動保存
- 操作ログの記録

## インストールと起動

### 1. Python環境の確認

Pythonがインストールされているか確認してください：

```bash
python --version
# または
python3 --version
```

Python 3.7以上がインストールされていることを確認してください。

### 2. 依存パッケージのインストール（初回のみ）

```bash
pip install -r requirements.txt
# または
pip3 install -r requirements.txt
```

### 3. アプリケーションの起動

#### Windows の場合
`run_peakpicker.bat` をダブルクリックするだけで起動します。

または、コマンドプロンプトで：
```cmd
run_peakpicker.bat
```

#### Linux/Mac の場合
ターミナルで：
```bash
./run_peakpicker.sh
# または
bash run_peakpicker.sh
```

#### 手動起動
```bash
python main.py
# または
python3 main.py
```

## UIコンセプト（マウス操作中心）

スペクトルレビューや軽微な編集を同じモードで完結させ、グラフ上のマウス操作だけでピークの採否判断やフィット、ズームまで行う方針です。

- 左クリック：最寄りのピーク候補を選択し、ラベルやテーブル行をハイライト
- 左ドラッグ：矩形で範囲を取り、ズーム／自動検出＋フィット／ROI保存を提示
- マウスホイール：カーソル中心にx軸ズーム、Ctrl + ホイールで縦軸スケール
- 右クリック：クリック位置に応じたコンテキストメニュー（採用／却下、単峰・多峰フィット、中心ズームなど）
- ダブルクリック：`proposed`⇔`accepted`のトグル、Shift + ダブルクリックで`rejected`

より詳細な操作仕様や画面レイアウト案は [docs/mouse_interaction_spec.md](docs/mouse_interaction_spec.md) を参照してください。

## 使い方

### 基本ワークフロー

#### 1. ファイルを開く
1. 「ファイルを開く」ボタンをクリック
2. MPAファイル（.mpa）またはCSV/TSVファイルを選択
3. スペクトルが表示されます

#### 2. ピーク同定（手動）
1. 解析モードで「ピーク同定」を選択
2. プロット上でピークの範囲の両端を2回クリックして範囲選択
3. 「選択範囲を自動フィット」ボタンをクリック
4. キャリブレーション未実施の場合、m/z値を入力

#### 3. m/z キャリブレーション
1. 少なくとも2つのピークを同定（既知のm/z値を入力）
2. 「m/z キャリブレーション」ボタンをクリック
3. キャリブレーション結果（A, B, R²）が表示されます

#### 4. 自動ピーク検出（キャリブレーション後）
1. X軸を「m/z」に切り替え（オプション）
2. プロット上で検出したい範囲を2回クリックで選択
3. 「範囲内ピーク自動検出＋フィット」ボタンをクリック
4. 検出されたピークが自動的にフィットされます

#### 5. 結果のエクスポート
1. 「結果をエクスポート」ボタンをクリック
2. 保存先とファイル名を指定
3. ピークリストがCSV形式で保存されます

### 積算モード

イオンカウントの積算を行う場合：

1. 解析モードで「積算」を選択
2. プロット上で積算範囲を2回クリックで選択
3. 自動的に積算が実行され、結果が表示されます
4. 同じm/z値に対して複数回積算すると、自動的に合計されます

### 表示機能

#### X軸の切り替え
- **TOF表示**: Time of Flight（飛行時間）で表示
- **m/z表示**: 質量/電荷比で表示（キャリブレーション後のみ有効）

#### ズーム操作
- **ズームイン (+)**: 表示範囲を狭める
- **ズームアウト (-)**: 表示範囲を広げる
- **全体表示**: スペクトル全体を表示
- **スライダー**: 表示範囲の中心位置を移動

#### ベースライン減算
1. BG減算欄に減算する値を入力
2. 「実行」ボタンをクリック
3. 空欄にして「実行」で元に戻す

### ピークテーブル

ピークテーブルには以下の情報が表示されます：
- **ID**: ピーク番号
- **TOF**: ピーク中心のTOF値
- **m/z**: ピーク中心のm/z値
- **Height**: ピーク高さ
- **FWHM**: 半値全幅（Full Width at Half Maximum）
- **Area(Fit)**: フィット曲線から計算した面積
- **Area(Int)**: 数値積分で計算した面積

テーブル上でピークをクリックすると、プロット上でそのピークがハイライト表示されます。

## トラブルシューティング

### ファイルが読み込めない

**問題**: MPAファイルを開こうとするとエラーが出る

**解決策**:
1. ファイルが破損していないか確認
2. ファイルが正しいMPA4 ASCII形式か確認
3. エラーメッセージに従って対処（エンコーディング、フォーマットなど）
4. 必要に応じてファイルをUTF-8で再保存

### フィットが失敗する

**問題**: 自動フィットボタンを押してもエラーが出る

**解決策**:
1. 選択範囲にピークが含まれているか確認
2. 選択範囲が狭すぎないか確認（最低4データポイント必要）
3. ノイズが多い場合は、BG減算を試す
4. 範囲を広めに取り直す

### m/z表示が選択できない

**問題**: m/z表示ボタンが無効

**解決策**:
1. m/z キャリブレーションを実行する必要があります
2. 最低2つのピークを同定してから、「m/z キャリブレーション」ボタンをクリック

### Python パッケージのインストールエラー

**問題**: pip install でエラーが出る

**解決策**:
1. pipを最新版にアップデート: `pip install --upgrade pip`
2. 管理者権限で実行（Windows: 管理者としてコマンドプロンプト実行）
3. 仮想環境の使用を検討:
   ```bash
   python -m venv venv
   # Windows
   venv\Scripts\activate
   # Linux/Mac
   source venv/bin/activate
   pip install -r requirements.txt
   ```

## 設定ファイル

アプリケーション起動時に `peakpicker_config.json` が自動生成されます。
このファイルには以下の設定が保存されます：

- ウィンドウサイズ

## 技術仕様

### キャリブレーション式
```
t = A * sqrt(m/z) + B
```
- t: Time of Flight
- m/z: 質量/電荷比
- A, B: キャリブレーション係数

### ピークモデル
現在実装されているモデル：
- **Gaussian**: amp * exp(-((x - center)² / (2σ²))) + offset

将来実装予定：
- **Voigt**: GaussianとLorentzianの畳み込み

### フィット品質指標
- **R²** (決定係数): キャリブレーションの精度
- **χ²** (カイ二乗): フィットの残差

## 開発情報

### モジュール構成

- **data_models.py**: データクラス定義（dataclass使用）
- **file_io.py**: ファイルI/O、堅牢なエラーハンドリング
- **calibration.py**: 非線形最小二乗法によるフィッティング
- **peak_fitting.py**: scipy.optimize.curve_fit, scipy.signal.find_peaks使用
- **gui*.py**: Tkinterベースのグラフィカルユーザーインターフェース

### 拡張性

新しいピークモデルを追加する場合：
1. `peak_fitting.py` にモデル関数を定義
2. フィット関数で model パラメータを追加
3. GUIに選択肢を追加
