# マウス操作中心のUIコンセプト

スペクトル解析をマウス中心で完結させるためのUI仕様案です。通常のブラウズと軽微な編集を同一モードで行い、必要最小限の追加モード（例：レビュー専用）を用意します。グラフ上での直感的操作だけで主要な作業が完結することを目指します。

## 1. 基本コンセプト
- 左クリック：選択
- 左ドラッグ：範囲選択
- 右クリック：位置に応じたコンテキストメニュー
- マウスホイール：x軸ズーム（Ctrl + ホイールで縦軸スケール）
- グラフ上でピークの採否・フィット・ズームが完結

## 2. マウス操作の仕様
### 2-1. 左クリック単発
- クリック位置に最も近いピーク候補（縦線）を選択。
- 選択状態では縦線色を変更（例：青→オレンジ）し、ラベル（TOF, m/z, FWHM, Area）を強調表示。
- 右側ピーク一覧テーブルの該当行も選択状態に同期。

### 2-2. 左ドラッグ（範囲選択）
- ドラッグ開始〜終了位置を薄い矩形で表示。
- ドラッグ解除時にポップアップまたは下部ボタンを有効化し、以下を提示：
  - 「この範囲をズーム」
  - 「この範囲のピークを自動検出＋フィット」
  - 「この範囲をROIとして保存」
- 将来的に「範囲内の候補ピークを一括採用／一括却下」も検討。

### 2-3. ホイール操作
- マウスホイール：カーソル位置を中心にx軸ズームイン/アウト。
- Ctrl + ホイール：縦軸（カウント）スケールの感度調整。

### 2-4. 右クリック（コンテキストメニュー）
- 右クリック位置に応じてメニューを出し分け。
- **ピーク候補上**
  - 「このピークを採用」
  - 「このピークを却下」
  - 「このピークを単峰フィット」
  - 「このピークと近傍を多峰フィット」
  - 「このピークにジャンプ（中心ズーム）」
- **ピーク候補のない場所**
  - 「ここを中心にズームイン」
  - 「ここから○○ ns 幅で範囲を作成」
  - 「この位置を背景基準点に登録」

## 3. ピーク候補の表示と採用フロー
### 3-1. 候補の見た目
- 自動検出ピーク候補は状態で表現：
  - `proposed`：青の点線
  - `accepted`：濃い実線
  - `rejected`：グレーの点線、もしくは非表示
- フィット済みピークはピークカーブを重ね、
  - 生データ：細線
  - フィット曲線：太線（色違い）

### 3-2. 採用・却下操作
- ダブルクリック：
  - `proposed` → `accepted`
  - `accepted` → `proposed`（トグル）
- Shift + ダブルクリック：`proposed/accepted` → `rejected`
- テーブル側のチェックボックスでも同じ操作を提供。

### 3-3. レビュー専用モード（任意）
- 「ピークレビュー」ボタンでモード突入し、最初の候補へ自動ズーム。
- キーボードショートカット：
  - `A`：採用
  - `D`：却下
  - `S`：スキップ
  - `→ / ←`：前後の候補へ移動
- 画面上に「残り候補数」「現ピークスコア」などを表示。

## 4. 画面レイアウト案
### 4-1. 上：グラフ、下：コントロールバー
- 上：メインプロット（ファイル名＋位置情報のタイトル、右上に凡例：Spectrum / Fit / PeakAccepted / PeakProposed…）。
- 下：操作バー
  - 「全体表示」ボタン
  - X軸切替（TOF / m/z）ラジオ
  - BG補正プルダウン（なし / 一定 / 線形）
  - 「範囲内ピーク自動検出＋フィット」
  - 「選択ピークを単峰フィット」
  - 「選択ピーク＆近傍を多峰フィット」

### 4-2. 右側：ピーク一覧テーブル
- 列例：採用フラグ、ID、TOF center、m/z center、Height、FWHM、Area、χ²/残差。
- 行クリックで該当ピークへズーム＋ハイライト。
- 列ソートにより、S/N高い順や幅が広い候補の確認を容易に。

## 5. 具体的なユーザーフロー
### フロー1：一括自動検出→人間レビュー→採用ピーク出力
1. ドラッグで範囲指定（例：m/z 0–100）。
2. 「範囲内ピーク自動検出＋フィット」を実行。
3. グラフに青点線の候補ピーク＋フィット曲線を表示、テーブルにも候補一覧を出力。
4. グラフ上で良さそうなピークをダブルクリックで採用、微妙なピークをShift + ダブルクリックで却下。
5. 「採用ピークのみCSV出力」でレポート生成。

### フロー2：単一ピークを丁寧にフィット
1. グラフ上でピーク付近をクリックして候補をハイライト。
2. 右クリックメニューから「このピークを単峰フィット」。
3. フィット曲線を重ね、パラメータをテーブルへ反映。
4. 結果が良ければ採用、ダメなら再フィットまたは手動調整。

## 6. 依頼書向けサマリ例
> グラフ上でのマウス操作を中心に、左クリック／ドラッグによるピーク選択・範囲選択、右クリックメニューによるフィット・採用／却下、ダブルクリックやショートカットキーによる採否トグルを実装し、ピーク自動検出結果を“候補”として提示したうえで、ユーザーが直感的に採否判断できるUIを構築してください。
